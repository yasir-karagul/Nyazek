# ADR-0007: Decisions from the IA consistency pass (T-0061)

- **Status:** Accepted
- **Date:** 2026-11-18
- **Decided by:** Claude, under ADR-0005. Each decision below adopts the recommended or a stricter option. Where a looser option exists that is reserved to the owner (ADR-0005 point 3.2), the decision says so; the owner can loosen it. Question 9 grants access and is reserved: it is not decided here (task T-0064). Question 16 is decided at the strictest option; wider access is also in T-0064.
- **Task:** T-0061
- **Source:** the 18 questions in `docs/reviews/documentation/2026-11-17-T-0060-ia-detail.md` (Disposition).

## Context

The T-0060 consistency pass removed page assertions that no rule supported and collected the questions those removals left open. Each answer below is a rule change in the PRD document that owns the topic; this record keeps the options and reasons. Cross-document impact was traced with the Graphify graph of `docs/` and checked in the source files.

## Decisions

## Consequences

- The PRD documents named in the "Where" column are updated in the same change, and the configuration register is regenerated.
- T-0064 holds the access questions for the owner: question 9 and the wider seller-staff access left open by question 16. For question 9 the current documents already give Support read access to the delivery log (NTF-5, sitemap `AD-NOT-LOG`) without a matrix row; the recommendation is to confirm that with recipients masked (RBAC-4), keep notification settings (`AD-SET-NOTIF`) with the Super Admin, and keep promotional campaigns (`AD-NOT-CAMP`) under "Promotions, loyalty, ads". This record changes none of that access.
- T-0019 (design briefs) can start once T-0061 is done.
